# ☕ Kafe Yönetim Sistemi (Cafe Management System)

C# ve .NET kullanılarak geliştirilmiş, temel kafe operasyonlarını yönetmek için tasarlanmış basit ve işlevsel bir uygulamadır.

A simple and functional cafe management application developed using C# and .NET to handle core cafe operations.

---

## 🚀 Özellikler | Features

### 🇹🇷
- 🪑 Masa yönetimi
- 🧾 Sipariş oluşturma ve takip
- 🛒 Ürün yönetimi
- 📊 Basit ve anlaşılır yapı
- 💻 Konsol tabanlı kullanım

### 🇬🇧
- 🪑 Table management
- 🧾 Order creation and tracking
- 🛒 Product management
- 📊 Simple and clean structure
- 💻 Console-based application

---

## 🛠️ Kullanılan Teknolojiler | Technologies

- C#
- .NET
- Object-Oriented Programming (OOP)

## ⚙️ Kurulum ve Çalıştırma | Setup & Run

### 🇹🇷
1. Projeyi klonlayın:
git clone https://github.com/ilydozttrk/KafeYonetim.git

2. Proje klasörüne girin:
cd KafeYonetim

3. Uygulamayı çalıştırın:
dotnet run

---

### 🇬🇧
1. Clone the repository:
git clone https://github.com/ilydozttrk/KafeYonetim.git

2. Navigate to the project directory:
cd KafeYonetim

3. Run the application:
dotnet run
